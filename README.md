# 📊 Financial Dashboard Login Screen

Uma interface moderna, responsiva e minimalista de tela de login desenvolvida para uma plataforma de monitoramento financeiro em tempo real.

---

## 🚀 Tecnologias Utilizadas

* **HTML5 & CSS3** (Semântica e estilização customizada)
* **Tailwind CSS** (ou a tecnologia que você usou, ex: *React / Next.js / Vue.js*)
* **Componentes de Formulário** (Validação visual e estados de foco)
* **Fontes & Ícones** (Integração com Lucide Icons / FontAwesome / Google Fonts)

---

## 🎨 Características do Design

* **Dark Mode Nativo:** Interface escura focada na redução da fadiga visual para traders e analistas.
* **Layout Split (Dividido):** Lado esquerdo com uma prévia visual do produto (gráfico de velas/candlesticks) e lado direito focado na conversão/acesso do usuário.
* **OAuth Integration:** Botões estilizados para login social via Google e GitHub.
* **Acessibilidade & UX:** Inputs com ícones internos claros, feedback visual e checkbox de persistência de sessão ("Lembrar minha senha").
